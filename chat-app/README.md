# Chat App (Frontend)

React + Vite frontend for the Agent Chat application. Uses MSAL for Microsoft Entra ID authentication.

## Development

```bash
npm install
npm run dev
```

Runs at `https://localhost:5173` with API proxy to `http://localhost:3000`.
